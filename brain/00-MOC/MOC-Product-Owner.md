## PO Responsibilities

| Activity | Cadence | Output |
|----------|---------|--------|
| Backlog refinement | Weekly (mid-sprint) | Stories ready for next sprint |
| Sprint planning | Per sprint start | Sprint goal + committed backlog |
| Sprint review | Per sprint end | Acceptance/rejection of increment |
| Stakeholder communication | Ongoing | Roadmap updates, demos |
| Discovery | Ongoing | New user stories, insights |

## INVEST Criteria (Good User Story)

| Letter | Meaning |
|--------|---------|
| **I** | Independent — doesn't depend on other stories |
| **N** | Negotiable — details can be discussed |
| **V** | Valuable — delivers value to user or business |
| **E** | Estimable — team can estimate it |
| **S** | Small — fits in one sprint |
| **T** | Testable — has clear ACs that can be verified |

## Backlog Item Priority Frameworks

**MoSCoW:**
- Must Have — sprint is failed without this
- Should Have — high value, not critical
- Could Have — nice to have
- Won't Have — out of scope this sprint

**RICE:**
- Reach × Impact × Confidence ÷ Effort
