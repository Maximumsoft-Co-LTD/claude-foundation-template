## PM vs PO

| | Product Manager | Product Owner |
|-|----------------|---------------|
| Focus | Strategy, Vision, Market | Execution, Backlog, Sprint |
| Horizon | 6-18 months | 1-3 sprints |
| Key output | Roadmap, PRD | User stories, ACs |
| In Scrum | Not a formal role | Core Scrum role |
| Stakeholders | Exec, Sales, Marketing, Users | Dev team, PO's stakeholders |

## Product Development Funnel

```
Market signals / User research
    ↓
Problem definition (Discovery)
    ↓
Solution hypothesis
    ↓
Experiment / Prototype / Validate
    ↓
Spec + Prioritization
    ↓
Build (Scrum/Dev)
    ↓
Launch + Measure
    ↓
Iterate or pivot
```

## Prioritization Frameworks

| Framework | Formula | Best For |
|-----------|---------|---------|
| RICE | (Reach × Impact × Confidence) ÷ Effort | Comparing many features |
| ICE | Impact × Confidence × Ease | Quick scoring |
| Kano | Delight vs Satisfy vs Must-be | UX decisions |
| Value vs Effort | 2×2 matrix | Visual alignment |

## North Star Metric Pattern

- One metric that best captures the core value delivered to users
- All teams can understand it and contribute to it
- Leading indicator of long-term success (not just revenue)

**Examples:**
- Spotify: Time spent listening
- Airbnb: Nights booked
- Slack: Messages sent
