# Atomic Note

An atomic note covers **exactly one concept, decision, pattern, lesson, or term** — nothing more. It links to related notes via `[[wikilinks]]` but stands on its own.

**Why atomic?** Claude (and humans) can load a single note into working memory and fully understand its topic without loading the entire vault. Notes remain reusable across different contexts.

**Naming convention in this project:**
- `CON-` prefix → concept
- `DEC-` prefix → decision (ADR)
- `PAT-` prefix → pattern
- `LES-` prefix → lesson learned
- `GLO-` prefix → glossary term

**This system is inspired by:** Zettelkasten, Niklas Luhmann's slip-box, and the LYT (Linking Your Thinking) framework.
